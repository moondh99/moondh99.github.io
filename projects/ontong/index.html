온통청년 문화·여가 접근성

경기도 청년 문화·여가 시설의 접근성 격차와 투자 방향을 살핀 공동 연구

팀 분석

이 사례에서 읽을 내용

배경과 목적진행한 일과정결과물성장과 결과직무 기여 역량다음 확인

배경과 목적

경기도 청년의 문화·여가 시설 접근성 격차를 살펴보고 입지와 투자 방향을 제안한 연구입니다. 경기연구원의 선행연구를 조사하고 공공데이터포털·경기도 데이터포털에서 자료를 찾았습니다.

청년시설과 청소년시설의 구분, 민간시설 포함 여부에 팀의 의견이 달랐습니다. 시설 이름보다 실제 이용 대상과 프로그램을 기준으로 볼 필요가 있다고 판단했습니다. 청년 연령대가 이용할 수 있는 청소년시설과 민간 문화·여가 활동도 고려했습니다.

진행한 일

배경
경기도 청년의 문화·여가 시설 접근성 격차를 살핀 3인 공동 연구입니다.
문제
시설 포함 범위에 의견이 달랐고 중간공유회 준비 일정이 늦어졌습니다.
핵심
이용 대상과 프로그램으로 시설을 검토하고 의정부·과천을 우선 살폈습니다.
해결 방향과 행동
교통 데이터·서버 업무를 맡고 공동 분석을 보고서와 입지·투자 방향 제언의 초안으로 정리했습니다.

과정

  1. 문제 정의

    범위 확인

    시설 포함 범위에 의견이 달랐고 중간공유회 준비 일정이 늦어졌습니다.

  2. 리서치

    조사 기록 확인

    선행연구와 공공·경기도 데이터 자료를 찾고 시설 포함 범위를 논의했습니다.

  3. 아이디어

    기획 범위 확인

    이용 대상과 프로그램으로 시설을 검토하고 의정부·과천을 우선 살폈습니다.

  4. 와이어프레임

    자료 미확보

    별도 와이어프레임 원본은 확보하지 못했습니다.

  5. 랜딩페이지

    범위 밖

    연구 보고서 또는 카드뉴스가 제출 산출물입니다. 서비스 랜딩페이지 제작은 이 사례에서 다루지 않습니다.

  6. MVP

    해당 없음

    공동 연구·보고서 프로젝트입니다. 서비스 MVP 제작 단계는 생략하고 보고서와 팀 수상을 결과로 봅니다.

담당과 협업

3인 팀 팀장·서버·교통 데이터 담당, 보고서·제언 초안 작성. 시설 정제는 팀원, 최종 보고서는 공동 결과, Claude는 문장 다듬기 보조입니다.

기록에 남은 행동

서버 구성과 버스·지하철 데이터 업무를 맡고 교통 데이터 전처리·통합 현황과 분석 방법을 팀과 논의했습니다. 인구·도로망·시설 데이터는 각 팀원이 담당했습니다.

팀 분석을 받아 보고서와 입지·투자 방향 제언의 초안을 직접 작성했습니다. 중간공유회에서 읽기 쉬운 보고서가 필요하다는 피드백을 받은 뒤 연구 질문과 제안을 이해할 수 있는 서술에 초점을 맞췄습니다. Claude는 문장 다듬기에 활용했습니다.

접근성 지수 시각화를 참고해 우선 투자 지역을 제안하고, 기존 시설의 프로그램 개선과 교통 연결도 고려했습니다. 최종 보고서는 3인의 공동 결과입니다.

판단과 확인 범위

시설 이름보다 실제 이용 대상과 프로그램을 기준으로 범위를 검토했습니다. 일정이 늦어진 때에는 현장 맥락을 확인하기 쉬운 지역부터 살피도록 범위를 좁혔습니다.

6월 27일 회의록·WBS중간공유회 최소 목표와 추진 계획계획을 완료 실적으로 계산하지 않음
중간공유회 자료담당표·현황·거주지역 범위 검토본인 정리, 팀 분석 활용
공동 보고서·제언접근성 분석과 우선 투자 방향본인 초안·팀 공동 보고서·Claude 문장 보조

성장과 확인한 결과

팀은 2025년 경기청년 연구 랩업(Lab Up!) 대상을 수상했습니다. 경기도 공식 보도자료는 2025년 11월 1일 결과공유회에서 온통청년 팀이 대상을 받았다고 명시합니다.

공동 보고서와 제언, 중간공유회 멘토링과 팀 수상이 확인됩니다. 정책 채택과 실제 접근성 개선 효과는 별도 확인이 필요합니다.

수상 근거 · 경기도 공식 보도자료

직무에 기여할 역량

조사 자료로 범위를 제안하고 일정에 맞춰 우선순위를 좁히며 공동 분석을 제언 문서로 정리한 경험입니다.

보완할 근거와 다음 확인

범위 조정으로 단축한 기간, 정제 전후의 지수 변화와 정책 효과는 미확정입니다. 전체 연구 기간과 11월 3일 활동 기록의 날짜 의미는 원문을 더 대조해야 하므로 하나의 종료일로 합치지 않습니다. 개인 후속 재분석도 제출 성과에서 구분합니다.
