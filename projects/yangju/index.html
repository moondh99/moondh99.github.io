0석과 정보 없음의 기준 설계

좌석 0·정보 미제공·수집 실패를 구분하는 명세를 작성하고, 관측 시각과 최신성을 원천·HTTP 응답 대조 기준으로 삼았다.

문제 발견의 근거

통근자가 좌석 정보를 살펴볼 때에는 관측된 값인지, 정보를 받지 못한 상태인지 이해할 수 있어야 한다. 외부 데이터가 화면과 API를 거쳐 전달되므로 값의 의미와 관측 시점을 응답 단계부터 구분할 필요가 있었다.

좌석 0은 자리가 없다는 관측값이다. 정보가 미제공됐거나 수집에 실패한 상황을 0으로 바꾸면 데이터 부재를 만석으로 읽게 된다.

선택과 이유

0은 유지하고 -1·null·잘못된 값은 0으로 치환하지 않도록 정했다. 빈 차량 슬롯은 후보로 만들지 않는다. 좌석·도착 예정 시간에는 수집 시각과 최신성을 붙이고 오래된 관측은 stale로 표시하는 기준을 마련했다. 검증 근거가 없는 예측값은 null로 남긴다.

본인 행동과 협업

4개 정류장과 6개 노선·방향의 매핑을 원천 응답과 로컬 HTTP 기록으로 대조했다. 데이터 항목·결측·최신성 기준을 명세로 정리하고, 읽기 전용 SQLite 어댑터와 current-seats API의 구현 결과를 검토했다.
