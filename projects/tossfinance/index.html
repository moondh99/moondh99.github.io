AI가 점수를 바꾸지 못하는 리포트

토스증권에 보유한 미국 주식을 읽기 전용으로 조회해 매일 아침 한국어 메일 리포트로 받는 개인 도구. 계산은 규칙, AI는 상위 3종목 해석만 맡김. 개인 리서치용이며 투자 자문이나 투자 권유가 아님.

01 · 무엇을 정했나

데이터와 계산이 먼저, AI 해석은 그다음

요구사항 문서의 목표는 매일 3~5분 안에 포트폴리오 상태, 어제와 달라진 점, 확인할 위험을 파악하는 것. 사용자는 본인 1명으로 한정함.

기각

AI가 전 종목을 계산하고 해석

같은 입력에도 결과가 달라질 수 있고 호출 비용이 종목 수만큼 늘어남

채택

계산은 Python 규칙, AI는 상위 3종목만

수익률, 비중, 종합 점수, 우선순위 점수는 규칙대로 계산. 우선순위 상위 3종목에만 분야별 분석과 최대 3라운드 찬반 토론 실행

채택

AI는 점수를 바꾸지 못함

AI 결과는 근거 데이터 경로를 함께 내야 하고, 점수나 위험 단계를 바꾸려는 출력은 거부되도록 테스트로 고정. 위험 단계별 점수 상한도 고정(치명 59, 높음 69, 중간 79)

채택

실패하면 중단 대신 축소

토스 인증이나 보유 종목 조회가 실패하면 실행 중단. 한 종목의 시세 계산, 공시, 뉴스, AI가 실패하면 해당 칸만 비우고 리포트 유지. 메일 발송 실패는 재시도

제외

주문, 자동매매, 투자 자문

토스 연동은 계좌와 보유 종목 조회 전용. 주문 관련 코드가 들어오면 정적 검사에서 실패하도록 함

운영은 토스 허용 IP 등록이 필요해 고정 IP 서버의 예약 실행으로 정함. 2026년 10월에는 금융 지식이 없는 독자 기준의 쉬운 한국어 규칙을 도입하고, 순서를 결론, 내 포트폴리오, 오늘 살펴볼 종목, 변화, 시장, 전체 종목으로 재설계함.

2026년 8월 29일부터 서버에서 매일 08시(한국 시간) 자동 실행. 초기 8일(8.29–9.5) 동안 리포트가 HTML과 텍스트로 저장되고 메일 수신까지 확인됨. 본인 메일로만 발송하므로 공개 링크 없음.
