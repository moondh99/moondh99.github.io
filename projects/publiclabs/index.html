모두의 AI 실험실 제안

놀이터 이동 안내를 중심으로 조례 피드백·공공사업 추적까지 담은 제안 초안(2026).

제안 초안

이 사례에서 읽을 내용

배경과 목적진행한 일과정결과물성장과 결과직무 기여 역량다음 확인

배경과 목적

처음 가는 놀이터에서 공용 출입구부터 놀이기구까지의 이동 순서를 장소 사진만으로는 이해하기 어렵다는 가설에서 출발했다. 연속 사진, 관찰 근거, 확인 날짜를 함께 보여 주도록 설계했다. AI 초안은 사람이 현장과 대조하고 승인한 뒤에만 게시한다.

진행한 일

배경
2026년 놀이터 이동 안내·조례 피드백·공공사업 추적 제안 초안입니다.
문제
장소 사진만으로 공용 출입구부터 놀이기구까지의 이동 순서를 이해하기 어렵다는 가설입니다.
핵심
연속 사진·관찰 근거·확인 날짜를 함께 보여 주도록 했습니다.
해결 방향과 행동
AI 초안을 사람이 현장과 대조·승인한 뒤 게시하는 PRD를 구성했습니다. 실제 답사·사용성 시험은 미완료입니다.

과정

  1. 문제 정의

    범위 확인

  2. 리서치

    답사 미완료

    실제 대상 선정·답사·사용성 시험은 완료하지 않았습니다.

  3. 아이디어

    기획 범위 확인

  4. 와이어프레임

    자료 미확보

    별도 와이어프레임 원본 미확보

  5. 랜딩페이지

    자료 미확보

    별도 랜딩페이지·운영 기록 미확보

  6. MVP

    제안 초안

    놀이터 이동 안내 PRD 등 제안까지입니다. 대상 선정·답사·사용성 시험은 미완료입니다.

담당과 협업

개인·팀·AI의 상세 기여는 확인 중입니다.

기록에 남은 행동

판단과 확인 범위

AI 초안을 현장과 대조한 뒤 사람이 게시를 승인하도록 설계했습니다. 계획한 답사·사진 수를 이미 수행한 결과로 계산하지 않습니다.

결과물

  • 놀이터 이동 안내 PRD
  • 조례 피드백 제안
  • 공공사업 추적 제안

성장과 확인한 결과

개인 학습·실사용 성과 기록은 확인 필요입니다.

직무에 기여할 역량

관련 업무는 현장 근거·확인 날짜·게시 승인 기준입니다. 개인 담당·수행 근거는 확인 필요입니다.

보완할 근거와 다음 확인

놀이터 2곳·경로 사진 4~7장은 향후 목표다. 실제 대상 선정·답사·사용성 시험은 미완료이며 개인·AI 상세 기여는 미확정이다.
