01 · 배경

질문에서 자서전 PDF까지, 역할별 흐름

자녀가 질문과 사진을 준비하고 부모님은 음성이나 글로 답함. AI가 받아 적고 다듬은 내용을 가족이 원문과 대조해 검토한 뒤 장에 추가하고, 마지막 산출물은 A5 자서전 PDF.

학기 중 본인 담당은 프런트엔드를 로컬 API와 SQLite 백엔드에 연결하고 사진·가족 질문·자서전 데이터를 DB에 잇는 작업. 6월에 개발 총괄을 맡음.

앱 화면은 모두 데모 계정의 가상 가족 데이터 · 2026.10 캡처

02 · 문제 정의와 실행

데모를 두 화면에서 직접 써 보고 이슈 10건으로 정리

개발 총괄을 맡은 뒤 부모님 화면과 자녀 화면을 각각 직접 사용. 걸리는 곳마다 캡처와 바꿀 내용을 붙여 팀 문서에 이슈 10건을 정의하고(2026.06.07 기준), 대부분을 직접 수정함.

  • 부모님·자녀 화면 모두의 글자 잘림과 줄바꿈
  • 동의 설정 화면 수정, 개발자 설정 숨기기
  • '사진 보고 이야기하기'와 '질문에 답하기'가 같은 화면으로 열리는 문제
  • 인터뷰 캘린더를 더 잘 보이는 곳으로 이동
  • 부모님 화면 모바일 대응, 고정된 책 표지와 실제 페이지 수 표시

03 · 선택지와 결정 · 후속 개인 작업

공개해도 되는 범위부터 정함

학기 후 7월부터 팀 과제와 별개로 개인 작업. 공개 범위, 동의 적용, 운영 정책을 아래처럼 결정함.

10월 9일 신규 가입과 기록 입력 개방

04 · 결과물

동의 정책이 화면이 된 모습

캡스톤경진대회 대상. 2026년도 국민대학교 경영정보학부 캡스톤경진대회, 참가 기간 2026.03.02–06.30, 6인 팀 수상.

후속 개인 작업. dear-log.com에 공개 소개와 가상 가족 샘플을 올리고, 롯데 공모전에는 단건 가격 가설과 90일 검증 계획을 담아 개인으로 제출.

AI 협업 범위. 후속 개인 작업의 구현은 AI 협업. 동의 적용, 보안, 공개 범위 결정은 본인.

05 · 정리

이슈 10건과 공개 범위 조정

부모님 화면과 자녀 화면을 각각 써 보며 캡처와 바꿀 내용을 붙여 이슈 10건 정리 (2026.06.07 기준).

공개 범위는 개발 진척에 맞춰 두 번 정함. 10월 초에는 샘플과 문의로 범위를 제한했고 이후 코드에 가입 진입을 추가. 소개 페이지와 실제 기능이 어긋나지 않도록 두 시점의 결정을 나눠 기록.
