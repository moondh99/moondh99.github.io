Dear Log

가족의 기억을 인터뷰로 남기고 자서전 PDF로 만드는 팀 서비스

화면 검토·이슈 정의

이 사례에서 읽을 내용

배경과 목적진행한 일과정결과물성장과 결과직무 기여 역량다음 확인

배경과 목적

보호자는 질문과 사진을 준비하고 결과를 검토하며, 시니어는 초대 링크로 들어와 답변합니다. 팀은 준비·인터뷰·가족 검토·PDF 제작을 잇는 흐름을 설계했습니다.

데모를 사용하면서 부모·자녀 화면의 글자 잘림과 줄바꿈, 동의 설정, 모바일 화면의 문제를 확인했습니다. 문제가 나타난 화면과 바꿀 내용을 함께 남겼습니다.

진행한 일

배경
가족의 기억을 인터뷰와 자서전 PDF로 남기는 팀 서비스입니다.
문제
데모에서 글자 잘림·줄바꿈·동의 설정·모바일 화면 문제를 확인했습니다.
핵심
팀은 보호자의 준비·검토와 시니어의 답변 역할을 나눴습니다.
해결 방향과 행동
문제가 나타난 위치와 바꿀 내용을 수정 요청 10건으로 전달했습니다.

과정

  1. 문제 정의

    범위 확인

    데모에서 글자 잘림·줄바꿈·동의 설정·모바일 화면 문제를 확인했습니다.

  2. 리서치

    검토 기록 확인

    데모를 사용하며 화면 문제를 확인했습니다. 사용자 인터뷰 원문은 미확보입니다.

  3. 아이디어

    기획 범위 확인

    팀은 보호자의 준비·검토와 시니어의 답변 역할을 나눴습니다.

  4. 와이어프레임

    화면 설계 기록

    팀 PRD·사용자 여정·화면 설계가 있습니다. 별도 와이어프레임 원본은 미확보입니다.

  5. 랜딩페이지

    자료 미확보

    서비스 소개·유입을 위한 별도 랜딩페이지 원본과 운영 기록은 미확보입니다.

  6. MVP

    데모 기록 확인

    팀 데모와 후속 구현 기록이 있습니다. 전체 기능 흐름·실사용 효과는 미확인입니다.

담당과 협업

학기 회의 자료에 백엔드·AI 에이전트 담당으로 기록됐고 6월 개발 총괄로 배정됐습니다. 확인된 개인 산출물은 데모 수정 요청 10건입니다. PM·UI/UX·에이전트 개발은 팀 분담이며 7~9월 AI 협업은 별도 후속 활동입니다.

기록에 남은 행동

학기 회의 자료에는 백엔드 연결과 에이전트 흐름 담당으로 기록돼 있고, 6월에는 개발 총괄로 배정됐습니다. 팀 PM·UI/UX·에이전트 개발에는 다른 팀원의 분담도 있었습니다.

6월 7일 변경 기록의 제 이름 아래 수정 요청 10건이 남아 있습니다. 각 항목에는 팀의 완료 표시가 있으며, 항목별 코드 수정 담당자와 재검증 결과는 별도 확인이 필요합니다.

판단과 확인 범위

화면 문제를 전달할 때는 문제가 나타난 위치와 바꿀 내용을 함께 남겼습니다. 팀의 완료 표시와 같은 화면의 재검증 자료는 구분해서 확인해야 합니다.

성장과 확인한 결과

확인한 결과는 본인 명의 요청 10건과 팀의 완료 표시입니다. 글자 잘림·동의 설정·모바일 화면의 수정 전 캡처 3건은 원문 첨부 참조가 남아 있습니다. 같은 화면의 수정 후 캡처는 확보하지 못했습니다.

현재 팀 설계와 파이프라인 전체를 개인의 학기 단독 구현으로 합산하지 않습니다. 캡스톤 대상은 기존 이력서 기록이며 수상 원본 대조가 남아 있습니다.

직무에 기여할 역량

화면 문제를 위치와 변경 내용이 담긴 요청으로 정리한 행동은 QA 이슈 정의와 개발팀 전달 업무에 연결됩니다.

보완할 근거와 다음 확인

항목별 수정 담당자·완료 시점·재검증과 동일 화면의 수정 후 캡처가 필요합니다. 동의 5종의 최초 도입 시점과 제안자, 전체 기능 흐름·SMS 연결·앱 배포·실사용 효과도 미확인입니다.
