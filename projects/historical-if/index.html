조선의 큰 사건에서 왕의 자리에 앉아 선택 10번을 내리는 역사 IF 게임. 선택마다 1만 개 평행세계를 시뮬레이션하고, 결과를 움직이는 가정마다 실록이나 승정원일기 기사를 근거로 연결. 2026년 10월 10일 시작, 커밋 106개.

역할

구현
코드와 테스트는 AI 협업(Claude), 장면 이미지는 Codex로 생성
01 — 무엇이 문제였나

근거 없는 '만약'

역사 IF는 그럴듯한 상상으로 흐르기 쉬움. 그래서 기획 문서(Implementation Plan v0.1)에서 사료, 모델, 게임 세 층을 나누고 사료 기사에서 주장, 가정, 규칙, 선택, 결과까지 거슬러 올라갈 수 있게 하는 것을 목표로 정함. 첫 범위는 광해군 1618~1623년으로 한정.

사료를 얻는 길부터 막힘. 실록 사이트는 자동 요청을 막고 공식 Open API도 없음. 마지막 에피소드인 병인·신미양요(1866~1871)는 확보한 실록 원문 묶음에 고종실록이 아예 없음.

“실록에 없는 장면은
가상이라고 표시한다.”

분기 사건과 장면 이미지에 붙인 원칙
02 — 무엇을 결정했나

사료 출처와 근거 연결 방식

  • 실록 · 채택공공데이터포털 실록 원문 XML국사편찬위원회가 공공누리 제1유형으로 공개한 파일을 받아 적재. 본문은 한문 원문. 음력 날짜를 양력으로 바꾸고 실록의 일진과 대조해 일치율 99.3% 확인.
  • 승정원일기 · 채택한국고전종합DB 국역본고종실록이 없는 병인·신미양요는 본인 결정으로 승정원일기 고종대로 대체. 목차를 따라 1초 간격으로 받아 캐시하고 1866~1871년 국역 기사 29,781건 적재.

근거 연결 방식도 정함. 기사 전부를 LLM 추출에 넣지 않고 결정과 관련이 깊은 기사부터 점수로 골라 주장(claim)을 뽑음. 시뮬레이션 가정마다 이 주장을 근거 링크로 붙임. 예를 들어 병자호란은 가정 11개에 근거 49개, 계유정난은 가정 10개에 근거 47개, 병인·신미양요는 가정 10개에 근거 52개 연결.

에피소드 구조는 선택 10번으로 고정. 점수 7개는 모두 0이 나쁜 방향이고 하나라도 0이 되면 그 자리에서 종료. 결정마다 실제 역사의 선택과 결과를 함께 보여 주고, 끝나면 실록 경로와 내 세계를 점수별로 비교. 실록과 다른 길로 갈라진 뒤의 사건에는 '가상 시나리오' 배지를 붙임.

서술 문단은 LLM이 쓰되 주어진 사실과 수치, 허용된 사건만 쓰게 하고 어기면 거부하도록 구현. 실제 역사 문구는 사료 원문과 대조 검토를 거쳐 과장되거나 근거 없는 문장 18개를 완화.

실록은 광해군 1618~1623년 5,913건, 인조 1627~1637년 6,815건 등을 적재. 병인·신미양요는 기사 59건에서 주장 314개를 추출. 결정 화면, 결과 화면, 실제 역사 비교, 점수 막대, 직접 입력한 명령의 선택지 해석까지 동작. FastAPI 백엔드와 React 웹, PostgreSQL 구성.

개인 프로젝트이며 코드와 테스트는 Claude와 협업해 작성. 사용자 지표는 포함하지 않음.

04 — 무엇이 남았나

진행 중인 항목

LLM이 추출한 주장은 아직 사람이 검토하지 않음. 6~8명 대상 대면 플레이 테스트는 질문지와 절차만 마련했고 미실시. 병인·신미양요 에피소드는 API 단위 확인까지만 기록되어 있고 브라우저 확인 기록은 없음.

현재는 로컬 실행만 가능. 공개 배포 예정.
