CampusGuard KIT 바이브코딩

부트캠프 출결 확인과 상담·행정 문서 작업을 5개 기능 영역으로 묶고, 모듈별 명세로 Kiro에 코드 생성을 요청해 만든 Streamlit 프로토타입.

프로토타입

이 사례에서 읽을 내용

배경과 목적진행한 일과정결과물성장과 결과직무 기여 역량다음 확인

배경과 목적

출결 확인과 상담·행정 문서 작업을 운영 흐름에서 함께 다루는 서비스를 검토했다. 관련 기능을 한 프로토타입 안에서 설명하는 것이 목적이다.

진행한 일

배경
2026년 4월 부트캠프 운영 지원 프로토타입입니다.
문제
출결 확인과 상담·행정 문서 작업을 한 운영 흐름에서 다루고자 했습니다.
핵심
출결·문서 초안·강의 질의응답·채팅 감성 분석·분석 이력의 5개 영역으로 나눴습니다.
해결 방향과 행동
기획 문서를 맥락으로 모듈별 명세를 Kiro에 전달한 생성 기록이 있습니다. 직접 명세·수정 범위는 확인 중입니다.

담당과 협업

Kiro가 모듈·데이터클래스·테스트를 생성했습니다. 본인의 명세 작성·직접 수정 범위는 확인 중입니다.

기록에 남은 행동

프로토타입 · 본인·AI 기여 상세 확인 중

기획 문서를 맥락으로 제공하고, 모듈별로 명세를 나눠 Kiro에 코드 생성을 요청한 기록이 있다. Kiro는 모듈, 데이터클래스, 테스트 코드를 생성했다.

판단과 확인 범위

기획 문서를 맥락으로 주고 명세를 모듈별로 나눠 요청한 생성 방식이 남아 있습니다. 생성 코드와 직접 수정한 코드를 구분해야 합니다.

결과물

저장소의 코드·테스트와 AI 리포트에 서비스 구성이 남아 있다. 예시 데이터를 사용한 프로토타입이며 실제 기관 도입과 운영 효과는 미검증이다.

성장과 확인한 결과

개인 학습·실사용 성과 기록은 확인 필요입니다.

직무에 기여할 역량

관련 업무는 AI 개발 요청의 모듈별 명세와 검토입니다. 개인 담당·수행 근거는 확인 필요입니다.

보완할 근거와 다음 확인

Kiro가 생성한 코드를 본인 직접 구현으로 합산하지 않는다. 본인의 명세 작성·직접 수정 범위는 확인 중이다.

예시 데이터 기반 프로토타입이며 실제 기관 도입·운영 효과·감성 분석 정확도는 검증하지 않았다.
