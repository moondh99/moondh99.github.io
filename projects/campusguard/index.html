CampusGuard KIT 바이브코딩

부트캠프 출결과 상담·행정 문서를 함께 다루는 프로토타입. Kiro 코드 생성 활용

프로토타입

이 사례에서 읽을 내용

문제와 사용자역할과 협업선택과 설계기획 흐름확인한 범위와 한계

문제와 사용자

부트캠프 출결 확인과 상담·행정 문서 작업을 운영 흐름에서 함께 다루는 서비스를 검토했습니다.

역할과 협업

프로토타입 · 본인·AI 기여 상세 확인 중

선택과 설계

출결 확인, 상담·행정 문서 초안, 강의 질의응답, 채팅 감성 분석, 분석 이력을 5개 기능 영역으로 묶은 Streamlit 프로토타입입니다. 기획 문서를 맥락으로 제공하고 모듈별 명세를 나눠 Kiro에 코드 생성을 요청한 기록이 있습니다.

기획 흐름

확인한 설계를 설명용으로 재구성한 흐름입니다.

  1. 출결 확인
  2. 상담 필요 확인
  3. 문서 준비
  4. 행정 업무 지원

확인한 범위와 한계

저장소의 코드·테스트와 AI 리포트에서 서비스 구성을 확인했습니다. Kiro가 모듈·데이터클래스·테스트 코드를 생성한 기록이 있으며, 본인의 명세 작성·직접 수정 범위는 추가 확인이 필요합니다. 예시 데이터를 사용했고 실제 기관 도입과 운영 효과는 검증하지 않았습니다.
