CampusGuard KIT 바이브코딩

부트캠프 출결 확인과 상담·행정 문서 작업을 5개 기능 영역으로 묶고 모듈별 명세로 Kiro에 코드 생성을 요청해 만든 Streamlit 프로토타입.

프로토타입

배경과 목적진행한 일과정결과물직무 기여 역량

배경과 목적

출결 확인과 상담·행정 문서 작업을 한 운영 흐름에서 다루는 서비스 검토. 관련 기능을 한 프로토타입 안에서 보여 주려는 것이 목적.

진행한 일

배경
2026년 4월 부트캠프 운영 지원 프로토타입.

출결 확인과 상담·행정 문서 작업을 한 운영 흐름에서 다루고자 함.
핵심
출결·문서 초안·강의 질의응답·채팅 감성 분석·분석 이력의 5개 영역으로 구분.

담당과 협업

본인: 5개 기능 영역 구분, 모듈별 코드 생성 요청 / Kiro: 모듈·데이터클래스·테스트 코드 생성

진행 방식
