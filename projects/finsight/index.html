PDF 난관을 나눠 대안 검토

증권사 리포트 수집 코드를 작성하고, PDF 처리 문제를 본문·표·이미지로 나눠 담당 팀원·멘토와 대안을 검토했다.

2025년 5인 팀 팀장·PM(일정·업무 배분·멘토 소통), FnGuide·WiseReport 기본 수집 코드 작성5인 팀 · 팀 웹서비스 배포

문제 발견의 근거

증권사마다 문서 형식이 달라 리포트와 컨센서스를 모으는 작업과 문서 내용을 읽어내는 작업이 필요했다. 팀은 수집과 파싱을 나눠 맡아 서비스 화면에 필요한 정보를 준비했다.

PDF 본문이나 표·이미지의 내용이 빠지면 화면에서 활용할 정보도 부족해진다.

선택과 이유

PDF 본문이나 표·이미지의 내용이 빠지면 화면에서 활용할 정보도 부족해진다. 처리 문제를 본문·표·이미지 유형으로 구분해 담당 팀원과 멘토에게 공유하고 대안을 검토했다.

로컬 코드에는 첫 페이지를 분리해 Docling으로 파싱하는 시도가 남아 있다. 이 자료는 대안 검토의 한 예이며, 최종 채택된 전체 파싱 방식으로 확정할 수 있는 범위는 아니다.

본인 행동과 협업

FnGuide의 전일 수집·날짜 범위 백필, WiseReport의 날짜 필터·Excel 내려받기를 다루는 기본 코드를 작성했다. 2025년 본인 계정의 추가·수정 이력으로 확인되는 구간이다. 팀 일정과 업무를 나누고 멘토에게 진행 상황을 공유하는 역할도 함께 맡았다.

확인한 결과와 검증

팀은 웹서비스를 배포했고, 대시보드·D-Day·D+1·상세 화면 자료와 수집 코드가 남아 있다. 별도 Flask 목업의 인증·DB는 시연용 구성이다.

2026년 AI 후속 구현·ETL 연결은 2025년 직접 작성한 수집 코드와 구분한다. 실제 사용자 테스트는 진행하지 못했으며 이용자 수와 투자 효과도 측정하지 않았다.

한계와 다음 확인

실사용 테스트·이용자 수·투자 효과와 수익률은 측정하지 않았다.

첫 페이지 분리·Docling 파싱은 로컬 코드의 시도 기록이다. 최종 채택 여부와 개인 작성 범위는 확정하지 않는다.

별도 Flask 화면 목업은 시연용이며 실제 인증·DB 동작과 배포 서비스의 기능을 증명하지 않는다. 개인의 전체 파싱·칸반 제작·단일 종료 월도 확정하지 않는다.
