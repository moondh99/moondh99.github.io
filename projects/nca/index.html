NCA 공약·공식자료 대조

정치인 공약 이행을 평가해 점수로 보여 주던 서비스. 사람 검수 없이는 점수를 뒷받침할 수 없다고 보고, 이행 판정을 내린 뒤 공약과 공식자료를 나란히 보여 주는 화면으로 전환함. 2025년 갭이어 2인 팀에서 시작해 2026년 개인 후속 작업으로 이어 감.

'정상 추진' 같은 판정을 화면에서 내리고 공식자료 대조로 전환. 허용·금지 문구 기준과 공개 조건 4가지, 공개 문턱 7% 선택
역할·기간

인정
2025 경기청년 갭이어 <기회 더하기> 프로젝트 플러스+ 선정(팀, 2025.11) · 후속 작업의 설계 초안과 코드는 AI 작성, 방향과 문구 기준은 본인 결정·수정

01 · 배경

2025년 목표는 이행률 점수 화면

2025 경기청년 갭이어에서 2인 팀 '국민중앙처'로 시작. 계획 단계 화면은 직무별 이행률 막대와 공약별 이행 상태를 보여 주는 점수 중심 구성.

본인 담당은 데이터 수집 파이프라인. 언론사별 뉴스 크롤러, 경기도·의정부시 공약 PDF 수집과 Gemini API 기반 공약 파서, 국회의원·발의법률안 적재 작업.

2026년 개인 후속. 2026년 7월부터 1인 운영으로 저장소를 이어 받음. 2026년 8월 24일 기준 발표 대상 공약 468건, 이행 라벨 120건, 종합 점수(WFI) 48.25를 화면에 노출하던 상태(로컬 DB·화면 점검 기준).

점검 결과. 검수 대기 147건, 팩트체크 판정은 2025년 10월 12일 이후 0건. 병목은 수집이 아니라 검수라는 점이 기록으로 확인됨.

02 · 문제 정의

근거 없는 점수를 계속 내보내는 상태

자료는 계속 쌓이지만 판정의 타당성을 확인하는 과정은 멈춘 상태. 화면에는 '정상 추진' 배지와 '추진 중인 근거를 확인했습니다' 같은 단정 문구가 그대로 노출됨.

  • 이행 라벨과 점수는 사람 검수를 전제로 설계된 지표
  • 1인 운영에서는 건별 검수를 다시 시작할 방법이 없음
  • 점수 데이터 키를 지우면 프런트엔드가 값을 자체 계산해 다시 표시하는 구조

자료에 대한 진술(연결·일치·날짜)은 한다. 공약 이행에 대한 진술은 하지 않는다.

모든 카드, API 응답, 테스트가 통과해야 하는 판정선으로 채택. "2025년 예산서의 '○○사업' 항목이 이 공약과 자동 연결되었습니다"는 허용, "이 공약이 추진 중인 것으로 확인되었습니다"는 금지.

03 · 선택지와 결정

점수는 내리고, 공개 범위는 조건으로 묶음

AI가 작성한 전환 설계 초안(rev 2, 2026.08.24)을 검토해 조건부 승인 4항으로 범위 확정. 사람이 개입하는 범위, 자료원별 탐색 상태, 완전 오탐률 기준을 명시하고 연결 건수는 성과 지표로 쓰지 않는다는 조건.

현 상태

평가 수치 계속 공표

검수하지 못한 판정이 화면에 계속 남음

기각

완전 무검수, 공식 식별자 일치만 공개

연결량이 지나치게 줄고 계약 대장에는 공약 번호가 없음. 최소 검수도 유지가 어려울 때의 후퇴 경로로만 남김

채택

최소 검수

건별 검수는 없애고 매처 버전을 내놓을 때만 표본 검증. '이행률 48점' 같은 헤드라인은 포기

채택

수치는 지우지 않고 공표만 중지

값은 null과 사유로 응답, 기존 판정 산출은 보존. 철수 공지와 대조 화면은 한 번에 반영

기각

연결률 순위와 커버리지 막대

연결 건수를 성과처럼 보이게 하는 지표라 제외

채택

공개 문턱: 완전 오탐 7% 이하

예산 매처 재확인 결과(실제 연결 135건 중 완전 오탐 9건, 6.7%)를 보고 여러 기준값 후보 중 본인이 선택

04 · 결과물

판정 대신 자료를 보여 주는 화면

전환은 2026년 8월 로컬 코드에 반영. 화면 문구상 철수일은 2026년 8월 25일. 공개 배포 여부와 실제 사용자 효과는 확인 범위 밖.

각 수치는 대상과 판정 방식이 다른 별도 기록이라 하나의 정확도나 개선율로 합산하지 않음.

  • 예산 연결 검증 표본. 튜닝에 쓰지 않은 18쌍 중 16쌍 적합, 95% Wilson 신뢰하한 67.2% (2026.07.31)
  • 뉴스 관계 재구축. 관계를 75건으로 줄인 뒤 전수 판정 결과 적합 26건(34.7%), 이전 기록은 422건 중 73건(17.3%). 공약 커버리지는 33%에서 9.7%로 감소 (2026.07.31)
  • AI 감사. 공약 세부 과제와 예산사업 후보 383쌍 중 완전 오탐 8쌍(2.1%), Wilson 상한 4.1%. AI 판정 기준 비율이며 사람 정답 검증은 아님 (2026.10.14)

05 · 정리

자료 연결과 이행 판단을 분리

자료가 연결됐다는 사실과 공약이 이행됐다는 판단을 문구, 배지, 집계 규칙에서 모두 분리. 작은 표본의 비율, AI끼리의 합의, 연결 건수는 각각의 범위 안에서만 쓰고 하나의 성과로 묶지 않음.
