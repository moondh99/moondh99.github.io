평가 수치에서 원문 대조로

공약과 관련 자료의 연결을 검토하고, 근거가 부족한 이행 평가 수치 공개를 중단해 공약·공식 자료를 대조하는 방향으로 바꿨다.

2025년 팀 데이터 엔지니어(수집·전처리·파이프라인·인프라 관리), 2026년 후속 작업의 AI 결과·공개 기준 검토 및 변경 승인2025 직접 수행 / 2026 AI 후속 검토

문제 발견의 근거

공약에 관한 기사를 찾는 것과 해당 공약의 이행을 확인하는 것은 다른 작업이다. 사용자가 판단의 근거를 확인하려면 어떤 자료가 공약과 연결됐고, 실제로 무엇을 뒷받침하는지 볼 수 있어야 한다.

2025년에는 기사와 공약 PDF를 모으고 저장 내용을 원문과 비교했다. 후속 작업에서는 수집된 자료를 어떤 기준과 형태로 공개할지 검토했다.

공약과 잘못 연결된 자료나 근거가 부족한 평가 수치를 그대로 노출하면 관련성에 대한 추정을 이행 판정으로 받아들일 수 있다. 사람의 검수에도 한계가 있어, 수치 자체보다 근거의 수준을 먼저 살펴야 했다.

선택과 이유

평가 수치 공개를 중단하고 공약과 공식 자료를 함께 보여주는 변경안을 승인했다. 인용·출처·주체·날짜를 확인하고, 근거가 부족할 때 판정을 유보하는 기준도 검토했다. 선택한 방향은 사용자가 원문을 확인할 수 있는 범위로 공개 내용을 조정하는 것이었다.

본인 행동과 협업

2025년에는 뉴스사별 크롤러와 Gemini API 기반 공약 PDF 파서를 작성하고 저장한 내용이 기사·PDF 원문과 맞는지 비교했다. 2026년에는 AI의 작업 결과와 공개 기준 변경을 검토했다.

확인한 결과와 검증

공약·공식 자료 대조 화면을 제공하고 평가 수치 공개를 중단한 변경 기록이 남아 있다. 2026년 10월 6일 로컬 기록에는 인용·스키마·유보·합의를 검증하는 흐름의 후속 구현·테스트가 있다.

이 후속 기록은 AI 협업의 구현 검증 범위이며 실제 모델 성능 평가 완료를 뜻하지 않는다. 사람 정답 검수와 사용자 효과는 아직 확정되지 않았다.

한계와 다음 확인

2026년 AI가 실행한 코드·테스트는 후속 구현 검증 범위이며 2025년 개인 직접 구현으로 소급하지 않는다.

사람 정답 검수·실제 모델 성능 평가·사용자 효과는 미확정이다. 모델 간 합의를 정답이나 정확도로 취급하지 않는다.

원문 대조가 기존 수치보다 정확하다는 효과 비교는 수행하지 않았다. 정확도·개선율은 기재하지 않는다.
