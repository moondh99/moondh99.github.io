후속 진행

이 사례에서 읽을 내용

문제와 사용자본인 역할과 협업선택과 이유구현·진행 과정확인한 결과한계와 다음 확인

문제와 사용자

사용자 상황 공약과 관련 기사에서 이행 근거를 직접 확인하려는 사용자.

공약과 관련된 기사라는 이유만으로 이행을 완료했다고 판단하기는 어렵습니다. 잘못 연결된 자료와 사람 검수의 한계를 검토했습니다.

본인 역할과 협업

2025년 팀의 데이터 엔지니어로 수집·전처리·파이프라인과 인프라 관리를 맡았습니다. 뉴스사별 크롤러와 Gemini API 기반 공약 PDF 파서를 작성하고 저장 내용을 원문과 비교했습니다.

2026년에는 AI의 작업 결과와 공개 기준을 검토·승인했습니다. 후속 AI 코드 실행을 2025년의 직접 구현과 구분합니다.

선택과 이유

공약 이행 평가 수치 대신 공약과 공식 자료를 함께 보여주기로 결정했습니다. 후속 AI 구현에서는 인용·출처·날짜를 확인하고, 근거가 부족할 때 판정을 유보하는 기준을 검토했습니다.

관련 자료를 찾은 것과 이행을 확인한 것은 다릅니다. 사용자가 근거를 직접 볼 수 있도록 자료 대조 화면을 제공하고, 근거가 부족한 평가 수치는 공개하지 않기로 했습니다.

구현·진행 과정

  1. 자료 수집

    2025년에는 뉴스사별 크롤러와 공약 PDF 파서를 작성해 원문 자료를 모았습니다.

  2. 원문 대조

    저장한 내용을 기사·PDF와 비교했습니다. 후속 검토에서는 인용·주체·날짜가 원문에 있는지 확인합니다.

  3. 공개 기준 변경

    이행 평가 수치 공개를 중단하고 공약과 공식 자료를 함께 보여 주는 변경안을 승인했습니다.

  4. 후속 AI 검토

    모델 간 합의와 사람의 정답 검수를 나눠 다룹니다. 상태를 뒷받침할 근거가 부족하면 판단을 유보하는 기준을 검토했습니다.

확인한 결과

2025 → 2026직접 수행과 AI 보조 후속의 역할 구분

자료 대조 화면을 제공하고 평가 수치 공개를 중단한 기록이 있습니다. 2025 경기청년 갭이어 우수 참여자로 선정됐습니다. 2026.10.06 로컬 기록에는 인용·스키마·유보·합의 검증 흐름의 구현과 테스트가 남아 있습니다.

한계와 다음 확인

후속 검증 흐름의 구현 기록을 실제 모델 평가 완료로 보지는 않습니다. 사람 정답 검수와 사용자 효과는 미측정이며, 정확도·개선율은 기재하지 않았습니다.
