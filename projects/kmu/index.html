국민대 특화 행정 서비스 AI

공식 학사 자료를 확인한 뒤 학생의 문의문과 체크리스트를 만들고, LLM의 역할을 좁혀 근거 없는 절차와 인용 누락을 검사하는 React·FastAPI 프로토타입.

구현·설계

이 사례에서 읽을 내용

문제와 근거설계 방향역할 범위현재 상태다음 확인

문제와 확인한 근거

공식 학사 규정을 확인하는 것에서 학생의 문의문·체크리스트와 다음 행동으로 이어지는 서비스를 검토했다. 공식 근거와 학생의 상태를 함께 다루는 흐름이다.

설계 방향과 범위

공식 근거 확인 → 학생 상태 점검 → 문의문·체크리스트 → 다음 행동 안내로 구성했다. 후속 설계에서는 LLM을 검색어 확장·근거 재정렬·표현 다듬기에 한정하고, 근거 없는 절차와 인용 누락을 검사하도록 했다.

초기와 후속 작업의 범위

캠퍼스 생활 AI 프로토타입 · 개인·팀·AI 기여 확인 중

작업은 두 시기로 나뉜다. 초기 작업은 공식 자료 수집과 RAG 기반 구성이고, 후속 작업은 화면과 안전검사 확장이다. 초기 작성 계정과 후속 계정이 서로 다르다.

결과물과 현재 상태

React·FastAPI 프로토타입과 검사 코드, 저장소의 당시 검증 기록이 남아 있다. 실제 이용 효과는 미측정이다.

결과물과 역할
구분확인한 산출물
확인 중초기 공식 자료 수집·RAG 기반 작업
확인 중후속 화면·안전검사 확장(React·FastAPI)
확인 중검사 코드와 저장소의 당시 검증 기록

다음 확인

초기 작성 계정과 후속 계정이 달라 전체를 본인 단독 구현으로 쓰지 않는다. 개인·팀·AI의 기여 구분은 추가 확인이 필요하다.

검사 코드와 당시 검증 기록은 현재의 정확도·실제 이용 효과를 증명하지 않는다.
