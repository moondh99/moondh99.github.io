첫걸음 동네산책

이주민이 동네 정보를 기록·공유하도록 환영길과 AI 안내 카드를 기획하고, 핵심 화면 4개에 예시 데이터를 넣은 MVP를 구성했다.

신청·MVP

이 사례에서 읽을 내용

배경과 목적진행한 일과정결과물성장과 결과직무 기여 역량다음 확인

배경과 목적

출발점은 하나의 가설이었다. 함께 동네를 걸은 뒤 혼자 다시 방문하려면 운영시간, 예약, 입구, 처음 해야 할 행동을 다시 찾아야 한다는 것이다. 목적은 이 정보를 기록하고 공유할 수 있게 하는 것이었다.

진행한 일

배경
이주민이 동네 정보를 기록·공유하는 서비스의 신청·MVP 단계입니다.
문제
동네를 함께 걸은 뒤 혼자 재방문할 때 운영시간·예약·입구·첫 행동을 다시 찾아야 한다는 가설입니다.
핵심
환영길과 AI 안내 카드에 혼자 다시 가는 단계를 별도로 뒀습니다.
해결 방향과 행동
3인 팀 대표로 팀원들과 Google Stitch 화면 4개를 만들고 예시 데이터를 넣었습니다.

  5. 랜딩페이지

    자료 미확보

  6. MVP

    핵심 화면 4개에 예시 데이터를 넣었습니다. 참가자 확보·현장 실증은 미확인입니다.

담당과 협업

3인 팀 대표, 팀원들과 Google Stitch 화면 공동 제작. 화면별 개인 담당과 PRD 작성자는 확인 중입니다.

기록에 남은 행동

3인 팀 대표 · 화면 공동 제작

Google Stitch로 팀원들과 핵심 화면 4개를 만들고, 예시 데이터를 넣어 MVP를 구성했다. PRD도 함께 남아 있다.

판단과 확인 범위

혼자 다시 방문하는 상황을 별도 화면 단계로 둔 설계입니다. 장소·인물·확인 배지는 예시이며 실제 재방문 결과는 측정하지 않았습니다.

결과물

결과물은 PRD와 예시 데이터 기반 화면 4개다. 화면 속 장소·인물·확인 배지는 예시이며 실제 운영 기록이 아니다. 참가자 확보와 현장 실증은 확인되지 않았다.

직무에 기여할 역량

팀 화면 공동 제작과 예시 MVP 구성 경험은 사용자 여정을 화면으로 옮기는 협업 업무에 연결됩니다. 개인 화면 담당은 확인 중입니다.

보완할 근거와 다음 확인

화면 속 장소·인물·확인 배지는 예시 데이터이며 실제 운영 기록이 아니다. 참가자 확보·현장 실증·선정 결과는 확인되지 않았다.
