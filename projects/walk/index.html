첫걸음 동네산책

3인 팀 대표. 이주민의 동네 정보 공유를 위한 핵심 화면 4개와 예시 데이터 MVP

신청·MVP

이 사례에서 읽을 내용

문제와 사용자역할과 협업선택과 설계기획 흐름확인한 범위와 한계

문제와 사용자

함께 동네를 걸은 뒤 혼자 다시 방문할 때 운영시간·예약·입구와 첫 행동을 다시 찾아야 한다는 가설에서 출발했습니다.

역할과 협업

3인 팀 대표 · 화면 공동 제작

선택과 설계

이주민이 동네 정보를 기록하고 공유할 수 있도록 환영길과 AI 안내 카드를 기획했습니다. Google Stitch로 팀원들과 핵심 화면 4개를 만들고 예시 데이터를 넣은 MVP를 구성했습니다.

기획 흐름

확인한 설계를 설명용으로 재구성한 흐름입니다.

  1. 환영길 시작
  2. 장소 카드
  3. 혼자 다시 가기
  4. 완주·소감

확인한 범위와 한계

PRD와 예시 데이터 기반 화면 4개가 있습니다. 화면 속 장소·인물·확인 배지는 실제 운영 기록이 아닙니다. 참가자 확보와 현장 실증은 아직 확인되지 않았습니다.
