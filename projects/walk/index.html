첫걸음 동네산책

이주민이 동네 정보를 기록·공유하도록 환영길과 AI 안내 카드를 기획하고, 핵심 화면 4개에 예시 데이터를 넣은 MVP를 구성했다.

신청·MVP

이 사례에서 읽을 내용

배경과 목적진행한 일과정결과물직무 기여 역량

배경과 목적

출발점은 하나의 가설이었다. 함께 동네를 걸은 뒤 혼자 다시 방문하려면 운영시간, 예약, 입구, 처음 해야 할 행동을 다시 찾아야 한다는 것이다. 이 정보를 기록하고 공유할 수 있게 하는 것이 목적이었다.

진행한 일

배경
이주민이 동네 정보를 기록·공유하는 서비스의 신청·MVP 단계입니다.
문제
동네를 함께 걸은 뒤 혼자 재방문할 때 운영시간, 예약, 입구, 첫 행동을 다시 찾아야 한다는 가설입니다.
핵심
환영길과 AI 안내 카드에 혼자 다시 가는 단계를 별도로 뒀습니다.
해결 방향과 행동
3인 팀 대표로 팀원들과 Google Stitch 화면 4개를 만들고 예시 데이터를 넣었습니다.

과정

  1. 문제 정의

    재방문 가설

  2. 아이디어

    환영길·AI 안내 카드

  3. 와이어프레임

    핵심 화면 4개

    팀원들과 Google Stitch로 핵심 화면 4개를 만들었습니다.

  4. MVP

    예시 데이터 MVP

    핵심 화면 4개에 예시 데이터를 넣어 MVP를 구성했습니다.

담당과 협업

본인: 3인 팀 대표 / 팀: Google Stitch 핵심 화면 4개 공동 제작, PRD

판단

함께 걸은 뒤 혼자 다시 방문하는 상황을 별도 화면 단계로 설계했습니다.

결과물

결과물은 PRD와 핵심 화면 4개입니다.

범위: 예시 데이터 기반 프로토타입(화면 속 장소·인물·배지는 예시)
