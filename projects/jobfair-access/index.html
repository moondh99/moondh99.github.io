MS Access 취업박람회 사전예약

취업박람회 사전예약 업무를 회원·기업·상담세션·예약·즐겨찾기·후기의 데이터 구조와 질의로 정리한 팀 설계 프로젝트.

팀 설계 프로젝트

이 사례에서 읽을 내용

배경과 목적진행한 일과정결과물성장과 결과직무 기여 역량다음 확인

배경과 목적

목적은 취업박람회의 사전예약 업무를 시스템과 데이터 구조로 정리하는 것이었다.

진행한 일

배경
2025년 취업박람회 사전예약 시스템 팀 설계 프로젝트입니다.
문제
사전예약 업무의 주체와 행동을 데이터 구조로 정리해야 했습니다.
핵심
회원·기업·상담세션·예약·즐겨찾기·후기의 6개 테이블 관계를 정의했습니다.
해결 방향과 행동
팀장으로 문서화를 맡았습니다. 후기·평균평점 자동 갱신 기능은 담당 배정 기록이며 구현 완료는 미확인입니다.

담당과 협업

팀장·프로젝트 문서화 담당. 시스템 설계·DB 모델링은 팀 작업이며 자동 갱신 기능의 구현 완료는 미확인입니다.

기록에 남은 행동

팀장 · 문서화, 시스템 설계·DB 모델링 참여

프로젝트 문서화를 맡았다. 원문에는 기업 후기·평균평점 자동 갱신 기능의 담당 역할이 적혀 있다. 다만 이 기능의 구현 완료 여부는 확인되지 않았다.

판단과 확인 범위

예약 업무의 주체·행동을 관계와 질의로 정리했습니다. 담당 배정과 기능 구현 완료는 서로 다른 확인 대상입니다.

결과물

팀 자료에는 6개 테이블 관계도와 평점 업데이트·기업 추천 질의 설계가 남아 있다.

결과물과 역할
구분확인한 산출물
팀6개 테이블 관계도(회원·참여기업·상담세션·예약 및 참여·즐겨찾기·후기)
팀평점 업데이트·기업 추천 질의 설계
개인프로젝트 문서화, 자동 갱신 기능 담당 배정

성장과 확인한 결과

개인 학습·실사용 성과 기록은 확인 필요입니다.

직무에 기여할 역량

프로젝트 문서화와 DB 관계 설계 경험은 업무 주체·행동·데이터 항목을 정리하는 서비스 기획에 연결됩니다.

보완할 근거와 다음 확인

기업 후기·평균평점 자동 갱신 기능은 담당 배정 기록이다. 구현 완료나 질의의 순차 실행으로 해석하지 않는다.

최신 Access 파일의 저장된 쿼리·폼·매크로, 최종 제출·운영 상태는 검증하지 않았다.
